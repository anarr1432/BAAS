# موقع شركة بأس للحاويات

موقع تعريفي ثابت جاهز للنشر على GitHub Pages.

## طريقة النشر على GitHub Pages

1. ارفع محتويات هذا المجلد إلى مستودع GitHub.
2. من إعدادات المستودع اختر Pages.
3. اختر النشر من الفرع الرئيسي `main` ومن المجلد الجذر.
4. احفظ الإعدادات وانتظر ظهور رابط الموقع.

## الملفات

- `index.html`: الصفحة الرئيسية.
- `styles.css`: التصميم والاستجابة للجوال.
- `script.js`: تحديث سنة الحقوق.
- `container-3d.js`: عارض ثلاثي الأبعاد لمقاسات الحاويات.
- `assets/`: الصور والبروفايل المستخدم في الموقع.
